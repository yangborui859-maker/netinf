# Print Method for looMultiAnalysis Objects

Prints a summary of leave-multiple-out analysis results, including
global strength changes and structural changes when multiple cases are
removed simultaneously.

## Usage

``` r
# S3 method for class 'looMultiAnalysis'
print(x, ...)
```

## Arguments

- x:

  An object of class `"looMultiAnalysis"`.

- ...:

  Additional arguments (currently unused).

## Value

Invisibly returns `x`.
